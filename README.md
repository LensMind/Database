# LensMind Optical Design Database

This repository contains automatically generated aspheric and spherical lens prescriptions.
The linked dataset READMEs describe their generation methods, file formats, and evaluation settings.

| Dataset | Lens prescriptions | Target specifications |
| --- | ---: | ---: |
| [Aspheric lenses](aspheric/README.md) | 500 | 50 |
| [Spherical lenses](spherical/README.md) | 147,329 | 13,090 |

## Getting the data

Clone this repository or use **Download ZIP** to obtain the complete [aspheric dataset](aspheric/lenses/) and [11 spherical examples](spherical/examples/).
The full spherical dataset is available from the [Releases page](https://github.com/LensMind/Database/releases).
